# Cursor Agent — инструкция для Артёма

**Дата:** 2026-08-31 · **Сеть:** домашняя Wi‑Fi GARAGE, **NetBird не нужен**

## Пакет на Pi 3

```
pi@10.0.20.56:~/artem-cursor-agent/
```

## Шаги на ПК (Windows)

### 1. Wi‑Fi GARAGE

ПК и малинка 3 в одной сети. Проверка:

```powershell
ping 10.0.20.56
```

### 2. Скачать пакет

```powershell
scp -r pi@10.0.20.56:~/artem-cursor-agent $env:USERPROFILE\Downloads\artem-cursor-agent
```

### 3. Установить Cursor Agent

```powershell
cd $env:USERPROFILE\Downloads\artem-cursor-agent
powershell -ExecutionPolicy Bypass -File install-cursor-agent-windows.ps1
```

### 4. Проверить

```powershell
ssh pi3 hostname
ssh kali hostname
agent --version
agent -p "ответь: OK"
```

| Команда | IP |

## Ключи (в пакете, не пересылать)

- `credentials/artem_ed25519` — SSH
- `credentials/cursor-api-key.txt` — API Cursor
