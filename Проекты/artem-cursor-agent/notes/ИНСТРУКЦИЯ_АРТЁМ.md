# Cursor Agent — инструкция для Артёма

**Дата:** 2026-08-31

## Что сделано

На Pi 3 лежит готовый пакет с SSH-ключом и API Cursor:

```
pi@100.102.186.61:~/artem-cursor-agent/
```

## Шаги на твоём ПК (Windows)

### 1. NetBird

Скачай https://netbird.io/ — войди в **семейный аккаунт** (как у папы). В трее должно быть **Connected**.

### 2. Скачать пакет

PowerShell:

```powershell
scp -r pi@100.102.186.61:~/artem-cursor-agent $env:USERPROFILE\Downloads\artem-cursor-agent
```

### 3. Установить Cursor Agent

```powershell
cd $env:USERPROFILE\Downloads\artem-cursor-agent
powershell -ExecutionPolicy Bypass -File install-cursor-agent-windows.ps1
```

### 4. Проверить

```powershell
ssh pi3 hostname
agent --version
agent -p "ответь: OK"
```

## Куда подключаться

| Команда | Что это |
|---------|---------|
| `ssh pi3` | Малинка в гараже |
| `ssh pi5` | Малинка на работе (основная) |
| `ssh kali` | Kali в гараже (через pi3) |
| `ssh pi5-wan` | Pi 5 по интернету без NetBird |
