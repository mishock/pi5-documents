# Режим проверки QR ячеек

Кидайте **строку кода** (24 символа) или **фото/скрин QR / Data Matrix**.

В ответ — максимум полей из декодеров (Xiho, Basen; Gobel/Hakadi — если доступны) + локальный разбор.

## Формат ответа

- Производитель, тип изделия, химия
- Ёмкость / модель, напряжение
- Дата производства, серийник, трассировка
- Статус формата кода и какие сайты ответили

## Быстрый запуск на Pi

```bash
python3 "Платы и модули/LiFePO4_Cell_QR_Decoder/scripts/decode_cell_qr.py" '04QCB72JB8800JFCF0021605' --save
```
