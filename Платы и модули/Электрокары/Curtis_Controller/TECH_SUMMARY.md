# Curtis Controller — техвыжимка

**Обновлено:** 2026-10-26

| | |
|--|--|
| Назначение | Тяговый мотор-контроллер (часто golf / LSV / industrial EV) |
| Индикация | 2 LED: **красный** + **жёлтый** (AC-серия 1232/1234/1236/1238…) |
| Чтение кода | 1×R → N×Y, 2×R → M×Y → код **NM** |
| Программер | Curtis 1311 / 1313 / 1314 (меню Fault / Monitor) |
| Онлайн-таблица | https://faultcodes.curtisinstruments.com/ |

Типичный запрос по LED «1 красный + 4 жёлтых, 2 красных + 7 жёлтых» = **47** (HPD/Sequencing), не «14+27». Подробности: `FAULT_CODES.md`.
