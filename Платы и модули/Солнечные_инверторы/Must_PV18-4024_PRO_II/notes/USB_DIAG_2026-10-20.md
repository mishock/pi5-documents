# Диагностика USB Must PV18-4024 PRO II — 2026-10-20

## Симптом

Инвертор «не включается», LCD мигает. Подключён USB к Raspberry Pi 5.

## Что на Pi 5

| Проверка | Результат |
|----------|-----------|
| `lsusb` | `1a86:7523` CH340 (USB Serial) |
| Порт | `/dev/ttyUSB0` → `usb-1a86_USB_Serial-if00-port0` |
| Подключение | hub `214b:7250`, устройство с **11:08** |
| Права | `dialout`, порт свободен |
| Modbus RTU | **нет ответа** (slave 1–5, baud 2400–115200, регистр 25205 и др.) |
| Спонтанный трафик | нет |

USB-адаптер на Pi **в порядке**. Связь с MCU инвертора **нет** — плата управления, похоже, не поднялась / не отвечает.

## Важно

- USB — **только мониторинг**, инвертор от USB **не питается**.
- Порядок из мануала: BAT **24 V** → автомат → **ON/OFF = ON** → затем USB к Pi.
- Тип АКБ **Li** без связи BMS на COM → по мануалу **мигает значок батареи** (прог. 14 → лучше **USE**).
- Код «соединение с аккумулятором открыто» / низкое U АКБ / BMS MOSFET open — типичные причины «мигает, не стартует».

## Что проверить у аппарата

1. На клеммах BAT инвертора мультиметром **~24–29 V** (не 0 и не 48 V).
2. Автомат/предохранитель на «+», полярность, BMS разряд включён.
3. Клавиша **ON/OFF** на корпусе — **ON**.
4. Код на LCD (ошибка/предупреждение) и цвет LED (красный мигает = warning/fault).
5. Если мигает только иконка батареи при **14=Li** и COM пустой — поставить **14=USE**.

После нормального старта: `bash scripts/must-dump-settings.sh` → ответ по Modbus 19200 slave 4.
