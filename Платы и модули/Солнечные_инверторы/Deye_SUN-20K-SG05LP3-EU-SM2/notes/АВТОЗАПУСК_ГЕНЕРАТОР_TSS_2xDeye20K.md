# Автозапуск ДГУ TSS → 2× Deye SUN-20K (трёхфазные)

**Дата:** 2026-10-23 (уточнение схемы с А. Аникеевым 20:00–20:01)

**Для выезда:** распечатать PDF `../generated/АВТОЗАПУСК_TSS_TQc22_2xDeye20K.pdf`  
**Инвертор (мануал на Pi 5):** `Deye_SUN-20K-SG05LP3-EU-SM2` — User Manual EN в `downloads/`  
**Генератор:** `Платы и модули/Дизельные_генераторы/TSS_TQc_22TS_ST_АД-16С-Т400/`  
**S/N ДГУ:** DG030000022116 · **16 кВт / 20 кВА** · 400 В 3ф 50 Гц

> «Гая / Диа» = **Deye** (тот же SUN-20K SG05LP3 на Pi 5).

**Схема по договорённости с монтажником:**
1. ДГУ питает **оба** инвертора.  
2. Сила: **один автомат «питание от генератора»** → оба INV (на щите помечены ИНВ1 / ИНВ2).  
3. Сухой контакт пуска **запараллелен**: неважно, кто дал команду — питание с ГУ идёт на оба.

---

## 0) Жёсткие ограничения

| Факт | Следствие |
|------|-----------|
| ДГУ всего **16 кВт** | Два инвертора по 20 кВт **нельзя** кормить на полную с GEN — лимит по ГУ |
| Сухой контакт **без напряжения** | CN2 G-start замыкает цепь; **не** подавать 12/230 В на G-start |
| Два G-start **параллельно** (НО) | Пуск, если **хотя бы один** замкнул; стоп, когда **оба** разомкнули |
| Один автомат GEN | Сила с ДГУ на **оба** порта GEN после общего автомата |
| Порт GEN | Режим **Generator Input**; SmartLoad / Micro Inv на этом порту — **ВЫКЛ** |

## 1) Железо — схема на завтра

### 1.1 Сигнал автозапуска (сухой контакт — параллель)

```
Deye INV1  CN2 G-start 1 ──┐              ┌── DIN ДГУ «40»
                           ├── параллель ──┤
Deye INV2  CN2 G-start 1 ──┘              │
                                          │
Deye INV1  CN2 G-start 2 ──┐              ├── DIN ДГУ «41»
                           ├── параллель ──┤
Deye INV2  CN2 G-start 2 ──┘              └──
```

Логика: контакты **нормально разомкнутые (NO)** двух инверторов соединены **параллельно** на одну пару Remote Start ДГУ.

| Кто замкнул | Результат |
|-------------|-----------|
| INV1 или INV2 (или оба) | Цепь 40–41 замкнута → ДГУ **старт** (AUTO) |
| Оба разомкнули | Цепь разомкнута → ДГУ **стоп** (после задержек контроллера) |

| Откуда | Куда | Кабель |
|--------|------|--------|
| INV1 + INV2 CN2 **G-start (1–2)** | DIN ДГУ **40** и **41** (параллель обеих пар) | 2×0,5–0,75 мм² на каждый INV до общей точки / Wago у щита |
| Gen Signal | **ВКЛ на обоих** | Иначе второй не сможет дать команду |

Если 40–41 не запускают ДГУ (тест §2): та же параллель → **22** и **0**.  
**Не** трогать **L** и **N1** для пуска.

Фото клемм: `Дизельные_генераторы/TSS_TQc_22TS_ST_АД-16С-Т400/pic/terminals_din_40_41_2026-10-23.jpg`  
Фото щита ИНВ1/ИНВ2: `…/pic/panel_INV1_INV2_GEN_breaker_2026-10-23.jpg`

### 1.2 Сила — выход ДГУ → оба GEN через один автомат

| Цепь | Подключение |
|------|-------------|
| ДГУ L1 L2 L3 N PE | → **один** автомат «питание от генератора» (~32–40 А под 16 кВт) → дальше **оба** порта **GEN** (ИНВ1 и ИНВ2) |
| Смысл | Кто бы ни стартовал ДГУ — напряжение приходит **на оба** инвертора |
| Автоматы ИНВ1 / ИНВ2 на щите | Отдельные линии инверторов (как на фото); общий ввод с ГУ — один |
| Не путать | Grid / Load — свои автоматы |

Порядок фаз ДГУ = фазы Grid на инверторах.

### 1.3 Параллель инверторов (если ещё не сведено)

- Кабель **Parallel_A / Parallel_B** Master ↔ Slave  
- LCD: один **Master**, второй **Slave**  
- Общие Grid / Load по схеме §3.13 мануала  
- BMS / батареи — как на объекте (эталон 2× RW-F16: Lithium Mode **00**, см. TECH_SUMMARY)

## 2) ДГУ — перед настройкой инверторов (5 минут)

1. Контроллер SmartGen: режим **AUTO** (не Manual).  
2. Аварийный Stop не нажат.  
3. Топливо / масло / ОЖ в норме.  
4. **Тест Remote Start без инвертора:** замкнуть **40–41** → пуск; разомкнуть → останов.  
5. Записать: рабочая пара = ☐ 40–41  /  ☐ 22–0.  
6. Ручной пуск с панели → убедиться 400 В / 50 Гц на клеммах силы.  
7. В меню Aux Input (если нужно): функция **Remote Start** (код **10**), активный тип — **замыкание**.

## 3) Меню Deye — **одинаково на обоих** (Gen Signal ВКЛ у обоих)

Путь: LCD → настройки (шестерёнка) → соответствующие экраны.  
Жёлтым в PDF — критичные. Колонка «Факт» — на объекте.

> Если инверторы в режиме Parallel (Master/Slave по связи): роли Master/Slave **для связи** остаются; для **сухого контакта** по схеме Аникеева — Gen Signal **ВКЛ на обоих**.

### 3.1 GEN PORT USE (`Generator Port Use`)

| Пункт | INV1 | INV2 | Пояснение |
|-------|------|------|-----------|
| **Generator Input** | ВКЛ | ВКЛ | Порт GEN = вход ДГУ |
| SmartLoad Output | ВЫКЛ | ВЫКЛ | Иначе порт станет выходом |
| Micro Inv Input | ВЫКЛ | ВЫКЛ | |
| GEN connect to grid input | ВЫКЛ | ВЫКЛ | ДГУ в GEN, не в Grid |
| **Rated Power** | **7000 W** | **7000 W** | Сумма ≈ 14 кВт ≤ 16 кВт ДГУ (оба берут с одного автомата). Альтернатива: 14000 на обоих + жёсткий Peak-shaving — хуже предсказуемо |
| On Grid always on | ВЫКЛ | ВЫКЛ | SmartLoad |

### 3.2 Battery Setup → экран с Gen Charge / Gen Signal

| Пункт | INV1 | INV2 | Пояснение |
|-------|------|------|-----------|
| **Gen Charge** | ВКЛ | ВКЛ | Заряд АКБ с GEN |
| **Gen Signal** | **ВКЛ** | **ВКЛ** | Параллель сухих контактов — любой может стартовать ДГУ |
| **Start** (SOC) | **25–30 %** | **то же** | Одинаковый порог, иначе один держит ДГУ, второй уже «полный» |
| **A=** ток заряда с GEN | **40 A** | **40 A** | Сумма ~80 A ≈ 4 кВт; запас ДГУ под Load. Подкрутить |
| Gen Max Run Time | 24.0 h | то же | 24 = без суточного стопа |
| Gen Down Time | 0–0.5 h | то же | Пауза перед следующим пуском |
| Grid Charge / Grid Signal | по объекту | то же | Не путать с Gen |

> Если заряд «только с Force»: либо SOC уже выше Start, либо поднять Start / кратковременно Gen Force.  
> **Gen charge stop % = 0**, если после «полной» АКБ нужно **оставить Load на ДГУ** (как на 6.6K: stop% ≠ 0 рвёт GEN и гасит Load с ГУ).

### 3.3 Advanced Function

| Пункт | Значение | Пояснение |
|-------|----------|-----------|
| **Gen Peak-shaving** | **ВКЛ** | Инвертор добирает из АКБ, если нагрузка > Rated Power ДГУ — критично при 16 кВт ГУ |
| Signal Island Mode | по ПУЭ/схеме | N–PE в off-grid — осознанно |

### 3.4 Parallel

| Пункт | INV1 | INV2 |
|-------|------|------|
| Role | **Master** | **Slave** |
| Parallel | ВКЛ | ВКЛ |

| Параметр | Значение |
|----------|----------|
| Rated Power | **7000 W** на каждом (сумма ~14 кВт) |

| Gen Charge ток | **40 A** на каждом (сумма ~80 A) |

## 8) Две АКБ / разный SOC — не заглушит ли второй?

**Параллель сухих контактов (NO):**  
пуск = ИЛИ (достаточно одного замыкания); стоп = И (оба разомкнули).  
Второй, «пытаясь запустить», **только замыкает** — цепь и так замкнута, **заглушить не может**.

**Реальный риск другой:** у кого АКБ выше Start — его Gen Signal открыт. Запустил тот, у кого SOC упал; он зарядился и разомкнул → ДГУ **встанет**, даже если второй «почти» низкий, но ещё **выше** порога Start (контакт ещё не замкнул).

**Как избежать:** одинаковый Start SOC на обоих; Gen charge stop% = 0 (если нужен Load с ГУ); по возможности не разводить сильно SOC банок; после стопа второй сам стартует, когда дойдёт до Start.

## 9) Объект (чат 2026-10-23, Аникеев)

- АКБ **314 Ah** (класс RW-F16) — ёмкость в меню Deye считать по факту сборки (1× / 2× на инвертор).
- Ферриты: «всё что трясётся» по инструкции; **кабели АКБ — сквозь кольца без обмотки** (для толстых DC так и делают: 1 проход).
- Сигнал G-start (тонкий) при наводках — кольцо/витки уместны; сила GEN — отдельно от сигнального жгута.
