## 0) Жёсткие ограничения

| Факт | Следствие |
|------|-----------|
| ДГУ всего **16 кВт** | Два инвертора по 20 кВт **нельзя** кормить на полную с GEN — лимит по ГУ |
| Сухой контакт **без напряжения** | CN2 G-start замыкает цепь; **не** подавать 12/230 В на G-start |
| Параллель 2 инвертора | Сигнал пуска — **только с Master**; Slave: Gen Signal **ВЫКЛ** |
| Порт GEN | Режим **Generator Input**; SmartLoad / Micro Inv на этом порту — **ВЫКЛ** |

## 1) Железо — схема на завтра

### 1.1 Сигнал автозапуска (управление)

```
Deye Master  CN2  G-start pin1  ─────┐
                                      ├──► DIN ДГУ  клемма «40»
Deye Master  CN2  G-start pin2  ─────┘         и «41»
```

| Откуда | Куда | Кабель |
|--------|------|--------|
| **Только Master** CN2 **G-start (1–2)** | DIN-рейка ДГУ **40** и **41** | 2×0,5–0,75 мм², витая пара / сигнальный, до 50–100 м ок |
| Slave G-start | **Не подключать** | Gen Signal на Slave = OFF |

Если 40–41 не запускают ДГУ (тест §2): та же пара G-start → **22** и **0** (Aux → B−).  
**Не** трогать **L** и **N1** для пуска.

Фото клемм: `Дизельные_генераторы/TSS_TQc_22TS_ST_АД-16С-Т400/pic/terminals_din_40_41_2026-10-23.jpg`

### 1.2 Сила — выход ДГУ → порт GEN

| Цепь | Подключение |
|------|-------------|
| ДГУ L1 L2 L3 N PE | Через **автомат ~32–40 А** 3P+N → **GEN** обоих инверторов **параллельно** (одинаковая фазировка L1/L2/L3) **или** сначала только Master — уточнить по факту щита |
| Автомат Grid / Load | Отдельные, не путать с GEN |
| Рекомендация мануала | Автомат GEN порта для 20K — до **100 А** (это потолок порта); **по ДГУ** ставить автомат **под 16 кВт** (~29–32 А), не 100 А |

Порядок фаз ДГУ = порядок фаз Grid на инверторах (иначе ошибка фазы / не примет GEN).

### 1.3 Параллель инверторов (если ещё не сведено)

- Кабель **Parallel_A / Parallel_B** Master ↔ Slave  
- LCD: один **Master**, второй **Slave**  
- Общие Grid / Load по схеме §3.13 мануала  
- BMS / батареи — как на объекте (эталон 2× RW-F16: Lithium Mode **00**, см. TECH_SUMMARY)

## 2) ДГУ — перед настройкой инверторов (5 минут)

1. Контроллер SmartGen: режим **AUTO** (не Manual).  
2. Аварийный Stop не нажат.  
3. Топливо / масло / ОЖ в норме.  
4. **Тест Remote Start без инвертора:** замкнуть **40–41** → пуск; разомкнуть → останов.  
5. Записать: рабочая пара = ☐ 40–41  /  ☐ 22–0.  
6. Ручной пуск с панели → убедиться 400 В / 50 Гц на клеммах силы.  
7. В меню Aux Input (если нужно): функция **Remote Start** (код **10**), активный тип — **замыкание**.

## 3) Меню Deye — заполнить на **обоих**, отличие только Gen Signal

Путь: LCD → настройки (шестерёнка) → соответствующие экраны.  
Жёлтым в PDF — критичные. Колонка «Факт» — на объекте.

### 3.1 GEN PORT USE (`Generator Port Use`)

| Пункт | Master | Slave | Пояснение |
|-------|--------|-------|-----------|
| **Generator Input** | ВКЛ | ВКЛ | Порт GEN = вход ДГУ |
| SmartLoad Output | ВЫКЛ | ВЫКЛ | Иначе порт станет выходом |
| Micro Inv Input | ВЫКЛ | ВЫКЛ | |
| GEN connect to grid input | ВЫКЛ | ВЫКЛ | ВКЛ только если ДГУ физически в Grid |
| **Rated Power** | **14000 W** | **14000 W** | Номинал ДГУ 16 кВт; запас ~2 кВт. Не 20000 |
| On Grid always on | ВЫКЛ | ВЫКЛ | SmartLoad |

### 3.2 Battery Setup → экран с Gen Charge / Gen Signal

| Пункт | Master | Slave | Пояснение |
|-------|--------|-------|-----------|
| **Gen Charge** | ВКЛ | ВКЛ | Заряд АКБ с GEN |
| **Gen Signal** | **ВКЛ** | **ВЫКЛ** | Сухой контакт пуска — только Master |
| **Start** (SOC) | **25–30 %** | то же | Ниже порога → автостарт |
| **A=** ток заряда с GEN | **80 A** старт | то же | ~4 кВт; оставить запас ДГУ под Load. Подкрутить по факту |
| Gen Max Run Time | 24.0 h | то же | 24 = без суточного стопа |
| Gen Down Time | 0–0.5 h | то же | Пауза перед следующим пуском |
| Grid Charge / Grid Signal | по объекту | то же | Не путать с Gen |

> Если заряд «только с Force»: либо SOC уже выше Start, либо поднять Start / кратковременно Gen Force.  
> **Gen charge stop % = 0**, если после «полной» АКБ нужно **оставить Load на ДГУ** (как на 6.6K: stop% ≠ 0 рвёт GEN и гасит Load с ГУ).

### 3.3 Advanced Function

| Пункт | Значение | Пояснение |
|-------|----------|-----------|
| **Gen Peak-shaving** | **ВКЛ** | Инвертор добирает из АКБ, если нагрузка > Rated Power ДГУ — критично при 16 кВт ГУ |
| Signal Island Mode | по ПУЭ/схеме | N–PE в off-grid — осознанно |

### 3.4 Parallel

| Пункт | INV1 | INV2 |
|-------|------|------|
| Role | **Master** | **Slave** |
| Parallel | ВКЛ | ВКЛ |

## 4) Порядок пусконаладки завтра (чеклист)

- [ ] Фото/сверка шильдика ДГУ (S/N DG030000022116)  
- [ ] Тест AUTO + замыкание 40–41 (или 22–0) без инвертора  
- [ ] Провод G-start **только Master** → рабочая пара DIN  
- [ ] Сила ДГУ → автомат → GEN (фазировка)  
- [ ] Master/Slave + Parallel OK  
- [ ] Меню §3 на обоих инверторах  
- [ ] Имитация: опустить SOC / Gen Force → ДГУ старт → на LCD **Generator** есть V/f/P  
- [ ] Нагрузка + заряд: ток GEN ≤ ~22–25 А/фазу (~15 кВт), ДГУ не захлёбывается  
- [ ] Разомкнуть Gen Signal / поднять SOC → ДГУ останавливается после cooldown  
- [ ] Записать в блокнот: Start %, ток A, Rated Power, рабочая пара клемм

## 5) Типовые значения «быстрый старт»

| Параметр | Значение |
|----------|----------|
| Rated Power | **14000 W** |
| Gen Start SOC | **28 %** |
| Gen Charge ток | **80 A** (потом 60–120 по нагрузке) |
| Gen Signal | Master ON / Slave OFF |
| Gen Peak-shaving | ON |
| Gen charge stop % | **0** (если Load должен остаться на ГУ) |

При **Li + BMS**: стоп заряда по BMS/Float; не полагаться на stop% как «хватит лить в АКБ».
