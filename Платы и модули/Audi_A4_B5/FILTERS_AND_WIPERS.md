# Audi A4 B5 — фильтры и щётки (Y921OE)

## Масляный фильтр

| | Артикул |
|---|---------|
| **OEM VAG** | **06A 115 433 E** |
| Кросс OEM | **06A 115 105 B**, **06A 115 561 B** |
| Mann | **W 712/75** |
| Bosch | **F 026 407 006** |
| Mahle | **OC 456** |

**Не подходит:** **04E 115 561 H** — для новых TSI (EA211, с ~2010), другая резьба/посадка.

**Кольцо:** **06A 115 440** (часто в комплекте с фильтром).

**Масло:** ~**4 л**; VW **502.00/505.00** или **10W-40** (для AHL допустимо по старым спекам).

## Щётки стеклоочистителя (передние)

**Седан B5:** лево и право **одинаковые — 530 мм** (≈21″), крепление **крючок (Hook)**.

| | Артикул |
|---|---------|
| **OEM VAG (1 шт.)** | **8D1 955 425 A** — нужно **2 шт.** |
| Кросс OEM | **8D1 955 425**, **8D9 955 425** |
| Bosch комплект | **AR 530 S** (AeroTwin 530+530) |
| Bosch | **3 397 118 400**, **3 397 001 583** |
| Bosch поштучно | **A 530 S** × 2 |
| Valeo | **578868** × 2 |

**Задняя щётка:** только на **Avant** — **380 мм**, OEM **8D9 955 427** (на седане нет).
