# HA + BLE с Pi 3 — АКБ 4S JK в гараже (не ANT)

**Обновлено:** 2026-10-31 (вечер, root-cause)

## Важно

- В гараже — **JK-B2A8S20P / AKB-4S-230** (`C8:47:80:53:0F:B6`), **не** ANT BMS24C.
- ANT24C — батарея у инвертора, опрос с **Pi 5**, дашборд отдельно.
- HA Pi5: дашборд **JK АКБ 4S 230Ah** → `/jk-akb-4s-230/home`, пакет `packages/jk4s.yaml`.

## Статус BLE (Pi 3)

- Scan видит **AKB-4S-230**.
- BlueZ рвёт линк; опрос через **Bumble HCI USER** (`/home/pi/jk4s-ble/`).
- Кадры `0x01` / `0x03` иногда приходят; полный **`0x02` (ячейки/SOC)** на встроенном Cypress UART часто обрывается (HCI reason 8/62).
- На Pi 5 (2026-10-30) тот же BMS отдавал стабильный `0x02` по bleak.

## На Pi 3

```bash
sudo systemctl status jk4s-ble-logger.timer
sudo systemctl start jk4s-ble-logger.service
journalctl -u jk4s-ble-logger -n 50 --no-pager
cat /home/pi/jk4s-ble/jk4s.json
```

Скрипт: `wake_and_poll.sh` (scan → опционально wifi off → Bumble → `publish_ha.sh`).

## Если offline

1. Закрыть JK App на телефоне.
2. Нажать кнопку на дисплее BMS.
3. Подождать 2–4 мин (таймер).
4. Надёжнее: USB BLE-донгл на Pi 3 (обход Cypress+Wi‑Fi).
