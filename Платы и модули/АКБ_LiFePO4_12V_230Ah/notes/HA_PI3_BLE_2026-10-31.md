# HA + BLE с Pi 3 — АКБ 4S в гараже

**Обновлено:** 2026-10-31

## Статус

- BLE-имя **AKB-4S-230**, MAC `C8:47:80:53:0F:B6` — Pi 3 видит в scan.
- BlueZ/bleak на Pi 3 (Cypress) не держит линк; опрос через **Bumble HCI USER**.
- Коннект бывает, кадры `0x01`/`0x03` приходят; стабильный `0x02` (ячейки/SOC) ещё ловится таймером.
- HA (Pi 5): дашборд **JK АКБ 4S 230Ah** (`/jk-akb-4s-230/home`), пакет `packages/jk4s.yaml`.

## На Pi 3

```bash
sudo systemctl status jk4s-ble-logger.timer
sudo systemctl start jk4s-ble-logger.service   # разовый опрос
journalctl -u jk4s-ble-logger -n 50 --no-pager
cat /home/pi/jk4s-ble/jk4s.json
```

Скрипты: `/home/pi/jk4s-ble/` (зеркало `Документы/bms-tools/jk4s_*`).

## Если offline

1. Закрыть приложение JK на телефоне (один централ BLE).
2. Нажать кнопку на дисплее BMS (разбудить BLE).
3. Подождать 2–4 минуты (таймер).
